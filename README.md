# toyworks-ad-lab

## Overview
This is a hands-on Active Directory lab simulating a small toy retailer built with Windows Server and VirtualBox to practice domain administration, DNS, user and group management, and IT troubleshooting.

## Objectives
- Deploy a Windows Server domain controller
- Configure Active Directory Domain Services
- Configure and troubleshoot DNS
- Create Users, groups, and organizational units
- Join a Windows client to the domain
- Implement Group Policy
